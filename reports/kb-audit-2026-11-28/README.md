2. **На странице «Клиенты и отзывы» вместо отзывов рыба.** Под подписью «Ирина Павловна Бочкова, Директор» напечатан пересказ шведского фильма «Триллер: Жестокое кино», у «Аршина» стоит описание FM-модулятора, ещё одна карточка называется «Новый отзыв нового клиента».
