# Мини-кейсы «Что сделали» (#1882, 09.11.2026)

Антон 09.11: улучшить карточки портфолио — по каждому клиенту собрать, что мы делали, и прикрепить к кейсу.

## Как устроено
- `cases/<client>.yml` — мини-кейсы клиента «задача → что сделали → результат», тип, дата, картинка (необязательно), `sources` (откуда факт: orch#, log, memory) и `notes` (для себя, на сайт не идут). Формат — в любом yml, например `merci.yml`.
- `publish.py` — проверка и выкладка. Без аргументов проверяет все yml (абсолютные цифры визитов/заявок, деньги, телефоны, e-mail, внутренние имена, технические слова). Выкладывает только с `--apply`:
  `python3 publish.py merci kppf --apply` или `python3 publish.py --all --apply` (все yml с `publish: true`, только изменившиеся, хэши в `.published.json`). Ключ с VPS — `/root/.ssh/ne-prosto_publish`.
- На хостинге: данные `~/ne-prosto/np-cases/<slug портфолио>.json` (вне webroot, 600, снаружи 404); картинки и стиль — `public_html/assets/neprosto/cases/` (`cases.css?v=N`, N = `CSS_V` в publish.py — при правке стиля повышать: у /assets/ кеш на год).
- MODX: сниппет `npCases` (id 99, исходник `modx/npCases.php`). В content кейса `[[!npCases]]` (некешируемый — новые данные видны сразу) перед кнопкой «Открыть сайт»; в чанке `np_project` после `<p>{$introtext}</p>` — `{$_modx->runSnippet('npCases', ['mode' => 'card', 'uri' => $uri])}` (теги + одна метрика; листинг кешируется, publish.py сбрасывает кеш). Нет json — вывода нет.
- Блок на странице: заголовок, счётчик по типам, до 8 свёрнутых карточек `<details>` (от свежих к старым), внутри «Задача / Что сделали / Результат» и картинки «до/после» или «как стало».

## Правила текста
- Только реальные факты. Цифры клиента — относительные (рост в разах/%, доли, индекс) — `memory/stageshow.md`. Объём сделанного студией (28 проблем, 7 правок) можно.
- Не кейс: доводка нашей же вёрстки по кругам Rix и «до/после» нашего дизайна (уточнение Антона 09.11), внутренняя кухня (бэкапы, PHP, падения автопилотов), инциденты безопасности, ошибки клиента.
- Rix-журнал — только источник дат и эффекта других работ.
