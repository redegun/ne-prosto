# NP—01: пробная машина айдентики
19.10.2026. Один самостоятельный визуальный концепт по запросу Антона попробовать направление «вымышленные устройства + миниатюрные сцены». Не утверждён для всей серии и не опубликован на сайте.

## Результат
- brand-machine.png — проверенный итоговый рендер 1800×1350.
- neprosto-brand-machine.blend — редактируемая сцена Blender 5.0, 249 объектов, процедурные материалы; Arial Bold упакован.
- build_brand_machine.py — воспроизводимый источник.

Сюжет: рулон бумаги → пресс с наборной буквой → подача через ролики → карточки и коробка. Графит, молочная эмаль, алюминий, лайм. Геометрия создана специально для студии, без сторонних моделей.

## Воспроизведение
blender -b --factory-startup -P build_brand_machine.py -- --out /temporary/render/folder
Добавить --draft для пробы 1200×900/48 samples. Итог: 1800×1350, Cycles/OptiX, 192 samples с denoise. Камера и свет сохранены в .blend.
Как и у предыдущей серии, локальная 4090 используется для временного рендера; канонические исходники и итоговые файлы возвращены в эту папку VPS.

## Проверка
Рендер просмотрен. Устранены висящие за корпусом вентиляционные элементы и разрывы рамки смотрового окна. На сайте ничего не заменялось. Две попытки image_gen завершились network / response decoding error; результат сделан непосредственно в Blender, не через запасной платный API.
