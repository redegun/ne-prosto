# Типографический концепт «Непросто»
19.10.2026. Автор запроса: Антон. Вариант NP—01 назван слишком похожим на настоящий станок и недостаточно соответствующим референсам. Текущее пожелание: больше фантазии, необычные формы, характер, фирменные цвета; попробовать типографическое направление из BUCK / IBM Think.
Создан один визуальный эскиз built-in image_gen: НЕ / ПРО / СТО, скульптурная композиция объёмных букв, графит, молочный, лайм, полупрозрачная лента О, фактуры металла. Это растровый концепт, исходника Blender для него пока нет. Отдельные формы оригинальные, референс не копировался.
