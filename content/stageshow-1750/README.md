## Данные для графика
Яндекс Метрика API, счётчик 26883291, `ym:s:visits` по `ym:s:lastsignTrafficSource=organic`, по месяцам. **API отдаёт данные только с 01.2022**: за 2014–2021 пусто у всех счётчиков с токеном METRIKA_TOKEN (проверено и на 37528015 и 22804270), поэтому «индекс 2019 = 1» сделать нельзя.
