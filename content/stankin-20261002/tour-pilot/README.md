# Экскурсия по поезду СТАНКИН

Опубликована 08.10.2026: https://ne-prosto.ru/portfolio/poezd-stankin#tour
Отдельный просмотр: https://ne-prosto.ru/images/portfolio/stankin/tour-20261008/

Восемь оригинальных вагонов, внутренние развёртки автора, свободное перемещение по проходу и маршрут из пяти точек. В кейсе модель запускается по кнопке; до нажатия iframe и GLB не загружаются. При смене вагона загружается только выбранная модель, ресурсы предыдущей освобождаются. Есть WASD/стрелки, экранные кнопки, pointer-drag, reset, fullscreen, ошибка/retry. Учтён prefers-reduced-motion.

## Источники и воспроизведение

Blender: https://disk.yandex.ru/d/0Nc9Z8zvb7svDQ
Внутренние текстуры: https://disk.yandex.ru/d/bdfd9VL_DXS0ZQ
Исходный .blend: 392512040 байт, SHA256 6a9e54fa27f889e2857b38e8c748fadac25d1ed6f72dd13b8ead931af1bec73f. Оригинал не пересохранялся. Антон явно разрешил временную обработку на office-pc. Папка: D:/project/tut/Clients/ne-prosto/.codex-tmp/stankin-tour/.

Blender 5.0.0: запускать --background --factory-startup --disable-autoexec, затем исходный .blend и --python tools/export_interiors.py -- НОМЕР_ВАГОНА ПАПКА_ОБРАБОТКИ. В папке обработки должны быть textures-browser/ и web/. tools/prepare_textures.py создаёт JPEG до 4096 px из оригиналов textures-interior/manifest.json. Исходники текстур не публикуются; они остаются на Яндекс Диске и временно на компьютере.

Файл Blender сообщил subversion 500.119. Все восемь экспортов успешно проверены в браузере: геометрия, UV, головы состава и размещение оформления. Станция, нулевой helper головного вагона и восемь технических Plane на высоте 66 м исключены. Головы 1/8 используют собственную геометрию и ограничения прохода, а не геометрию среднего вагона.

## Размеры и ограничения

Draco GLB: 2.52–2.93 МБ на вагон, все восемь — 21.8 МБ. 148680 треугольников на обычный вагон, 150764 на головной. Текстура 4096² JPEG встроена в каждый GLB. Материалы салона упрощены для браузера, авторская графика и исходные UV сохранены. Это интерактивная рабочая модель, не фотография и не полноразмерный печатный макет.

Three.js 0.186.1 и Draco decoder поставляются локально из vendor/; внешнего CDN при просмотре нет. Лицензии включены. models-manifest.json хранит размеры, SHA и источники. Старый pilot-geometry.glb оставлен только как исторический технический образец и не выгружается на сайт.

## Исправление диагностики текстур

Первоначальные 24 отсутствующие ссылки / 11 имён относились ко всем image datablock, включая отключённые ноды. В каждом вагоне реальное оформление подключено к одному материалу. В частности, для_3д_1.jpg в Color_000.009 и Развертка_2_вагон.jpg в Резина_2.086 не соединены с шейдером и НЕ нужны для интерьера. Все восемь активных карт оформления заменены предоставленными внутренними развёртками. Не подключать графику к резине/белым панелям по одному факту наличия image-ноды.

Верхняя часть внутренних атласов белая: внешнее оформление пока отсутствует. Кнопка внешнего осмотра скрыта в опубликованном интерфейсе. Доработка экстерьера — issue #2; внутренний тур уже работает.

## Деплой и откат

Живой сайт — MODX на Timeweb, ресурс 100. Корневой index.html репозитория — старый макет. tools/deploy_tour.py читает доступы только на VPS, публикует whitelist файлов в /images/portfolio/stankin/tour-20261008/ и обновляет контент с проверкой SHA.

До изменения сохранено sources/before-tour-20261008/resource.json и content.html (вне git). Изменён только контент resource 100 и новый каталог ассетов. После публикации служебный endpoint перенесён за пределы webroot, его URL возвращает 404. Для отката восстановить content из backup через MODX API; общие шаблоны не затрагивать. Не запускать prepare повторно без проверки старого endpoint state.

Локальный просмотр обновлён: http://127.0.0.1:8766/. Python http.server слушает только 127.0.0.1. Проверять фактический процесс, не полагаться на сохранённый PID.
