# Черновик экскурсии по вагону СТАНКИН

Статус: технический прототип, НЕ опубликован в портфолио. Антон 02.10.2026 разрешил временно обработать исходник на office-pc, так как на VPS осталось 486 МБ. Blender 5.0 установлен; GPU RTX 4090. На VPS хранятся код, производная GLB и отчёты; исходный .blend 393 МБ остаётся в локальной временной папке и на Яндекс Диске.

Локальный предпросмотр: http://127.0.0.1:8766/
Рабочая временная папка: D:/project/tut/Clients/ne-prosto/.codex-tmp/stankin-tour/
Сервер: встроенный Python Blender 5.0, http.server 8766, bind 127.0.0.1, --directory .../web. Процесс при подготовке запущен скрыто, PID 55616 (перед управлением проверить текущую команду процесса).

Прототип использует геометрию vagon3. GLB 9.13 МБ, 148680 треугольников. Станция и другие вагоны исключены. Режимы: снаружи / внутри / маршрут из пяти точек. Внутри движение ограничено проходом; есть экранные стрелки, мышь/палец, клавиши WASD и стрелки, возврат к исходному виду и fullscreen.

Финальное оформление заблокировано: 24 отсутствующих image-ссылки, 11 уникальных JPG. Для vagon3 нужны Вагон_3.jpg, Развертка_2_вагон.jpg, для_3д_1.jpg. Антон ответил «да пришлю». В присланном ранее Яндекс Диске проверены 169 папок и 1997 файлов; изображения по исходным именам не найдены. Список: missing-textures.json.

Текущий prepare_pilot.py создаёт ТОЛЬКО нейтральную геометрию для проверки перемещения: материалы заменены упрощёнными однотонными вариантами, оригинальная бренд-графика не включена. После получения текстур написать отдельный финальный экспорт, который сохраняет оформление и UV. Исходник никогда не пересохранялся. Blender при чтении сообщил более новую подверсию файла 500.119: перед финальным экспортом сравнить геометрию/модификаторы и при необходимости использовать совместимую сборку.

Three.js 0.186.1 закреплён, модули и MIT LICENSE лежат в vendor/. Открывать через HTTP, не file://. Для воспроизведения перенести готовый каталог на машину с браузером и запустить python -m http.server --bind 127.0.0.1 из него. На публичном сайте текущий черновик не размещать.
