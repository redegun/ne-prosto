# Экскурсия по поезду СТАНКИН

Опубликована 08.10.2026: https://ne-prosto.ru/portfolio/poezd-stankin#tour
Отдельный просмотр: https://ne-prosto.ru/images/portfolio/stankin/tour-20261008/

Восемь оригинальных вагонов, внутренние развёртки автора, свободное перемещение по проходу и маршрут из пяти точек. В кейсе модель запускается по кнопке; до нажатия iframe и GLB не загружаются. При смене вагона загружается только выбранная модель, ресурсы предыдущей освобождаются. Стартовый вагон — № 1. Есть WASD/стрелки, экранные кнопки, pointer-drag, приближение «Ближе» (FOV 28° вместо 58°), reset, fullscreen, ошибка/retry. Учтён prefers-reduced-motion.

## Размеры и ограничения

Draco GLB: 2.52–2.93 МБ на вагон, все восемь — 21.8 МБ. 148680 треугольников на обычный вагон, 150764 на головной. Базовая текстура 4096² JPEG встроена в каждый GLB. Для близкого осмотра detail-textures.js подгружает видимые участки исходных атласов 24000–25000 px: сетка 8×8, четыре пикселя запаса по краю, native JPEG 3000–3125 px и мобильные версии до 1600 px. Одновременно резидентны не более шести фрагментов (четырёх на ширине до 720 px); при повороте и смене вагона старые текстуры освобождаются. Общий комплект 196096633 байта не загружается целиком. При недоступном HD-фрагменте остаётся базовый атлас, повтор запроса не чаще чем через 30 секунд. Авторская графика и исходные UV сохранены. Это интерактивная рабочая модель, не фотография и не полноразмерный печатный макет.

Three.js 0.186.1 и Draco decoder поставляются локально из vendor/; внешнего CDN при просмотре нет. Лицензии включены. models-manifest.json хранит размеры, SHA и источники. Старый pilot-geometry.glb оставлен только как исторический технический образец и не выгружается на сайт.

## Материалы, свет и чёткость

В appearance.js настроены тёмный графитовый пол (Fabric126 — это пол, а не сиденья), тёмно-синий материал seatcushion, тёплый белый пластик и металлические поручни. Стёкла — MeshPhysicalMaterial с transmission, за ними тёмная условная станция: перрон, колонны, стены с швами и редкие локальные светильники. Это художественный фон, а не реконструкция конкретной станции. RoomEnvironment даёт отражения; направленные вниз светильники заменили точечные источники, пересвечивавшие потолок. Экспозиция 0.9, умеренный заполняющий свет. По просьбе Антона пол затемнён до #25292d; включено свечение оригинальных потолочных ламп (имена материалов проверены в Blender, reports/lights-audit.json). Четыре внешних источника с ограниченным радиусом создают отдельные световые участки на тёмной станции; фон остаётся приглушённым. effects.js добавляет GTAO для контактов и глубины, MSAA и OutputPass. Браузер рендерит модель в реальном времени; это не запечённый рендер Cycles.

Подготовка фрагментов: tools/prepare_detail_tiles.py ПАПКА_ОБРАБОТКИ. Нужны Pillow, исходные textures-interior/ и web/. Материалы исправляются в браузере, повторный экспорт GLB не нужен. Не возвращать сплошной уменьшенный атлас как единственный источник близких надписей.

## Исправление диагностики текстур

Первоначальные 24 отсутствующие ссылки / 11 имён относились ко всем image datablock, включая отключённые ноды. В каждом вагоне реальное оформление подключено к одному материалу. В частности, для_3д_1.jpg в Color_000.009 и Развертка_2_вагон.jpg в Резина_2.086 не соединены с шейдером и НЕ нужны для интерьера. Все восемь активных карт оформления заменены предоставленными внутренними развёртками. Не подключать графику к резине/белым панелям по одному факту наличия image-ноды.

Верхняя часть внутренних атласов белая: внешнее оформление пока отсутствует. Кнопка внешнего осмотра скрыта в опубликованном интерфейсе. Доработка экстерьера — issue #2; внутренний тур уже работает.

## Деплой и откат

Живой сайт — MODX на Timeweb, ресурс 100. Корневой index.html репозитория — старый макет. tools/deploy_tour.py читает доступы только на VPS, публикует whitelist файлов в /images/portfolio/stankin/tour-20261008/ и обновляет контент с проверкой SHA.

До изменения сохранено sources/before-tour-20261008/resource.json и content.html (вне git). Изменён только контент resource 100 и новый каталог ассетов. После публикации служебный endpoint перенесён за пределы webroot, его URL возвращает 404. Для отката восстановить content из backup через MODX API; общие шаблоны не затрагивать. Не запускать prepare повторно без проверки старого endpoint state.

Обновление качества: tools/deploy_quality.py backup / publish. Сохраняет live index/tour/loader/CSS в sources/before-quality-20261008/, загружает только новые detail/vendor-файлы и изменённый плеер, проверяет размер и переименовывает временный .upload. index.html публикуется последним. Состояние возобновления — upload-state.json вне git; CMS и служебные PHP-endpoint не нужны. Для отката достаточно восстановить четыре live-* файла из бэкапа; новые невостребованные ассеты можно оставить.

Контрастный вариант contrast1: бэкап перед ним — sources/before-contrast-20261008/ (appearance, tour, loader, index; также live-* с хостинга). Для отката восстановить эти четыре файла. Модели и HD-текстуры в этой итерации не менялись.

Локальный просмотр обновлён: http://127.0.0.1:8766/. Python http.server слушает только 127.0.0.1. Проверять фактический процесс, не полагаться на сохранённый PID.
