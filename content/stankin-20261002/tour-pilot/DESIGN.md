# Экскурсия СТАНКИН

Основной сценарий — рассмотреть авторское оформление снаружи и внутри восьми вагонов. Запуск в кейсе по кнопке поверх рабочего рендера; тяжёлая модель загружается только по выбору посетителя.

Структура: первый вагон по умолчанию, выбор вагона, режимы «Снаружи» / «Внутри» / «Экскурсия», приближение «Ближе», сброс, полный экран. Свободное перемещение ограничено проходом; головы состава имеют отдельные границы перед кабиной. Пять точек маршрута показывают вход, обе стены, центр и обратную перспективу.

Белый фон, чёрные кнопки активного режима, красный focus-visible. На мобильной ширине режимы и вспомогательные кнопки расположены в два ряда, экранные стрелки не перекрывают маршрут. Встраивание адаптировано через ?embed=1; вводная часть скрыта, iframe имеет собственную фиксированную высоту.

Состояния: loading/progress, ready, pressed, disabled, hover/focus, load error/retry, fullscreen. Reduced motion отключает переходы камеры. Ошибка не убирает фотографии исходного кейса. Есть отдельная ссылка на просмотр при отключённом JavaScript интеграции.

Наружный и внутренний осмотр используют одну геометрию, авторские развёртки совмещены в исходных UV. Снаружи вагон можно вращать, приближать и сдвигать; камера вписывает его целиком на любой ширине. При смене вагона выбранный внешний режим сохраняется. Для внешнего вида используется нейтральный свет без декораций станции, для интерьера — ранее согласованная контрастная сцена. В продуктовых текстах нет служебных сообщений о Blender, конвертации, отсутствующих текстурах или тестовом прототипе.

Визуальная подача: светящиеся потолочные лампы, умеренный нейтральный свет, тёмный графитовый пол, тёмно-синие сиденья, металлические поручни, прозрачные окна. Авторские цвета оформления не перекрашиваются. При близком осмотре нужные участки графики подгружаются в высокой чёткости; базовый атлас остаётся доступен во время загрузки. За окнами — тёмная условная станция с колоннами, перроном и отдельными включёнными светильниками. Светлый салон и цветная графика выделяются на тёмном фоне; конкретная станция не воспроизводится.
