# Новая категория на странице /uslugi/ под ИИ-услуги (задача #507)

Запрос Лены: категория «Автоматизация» или «Интеграция ИИ», первая услуга — хаб «ИИ-ассистент для бизнеса» (#501, /uslugi/ii-assistent-dlya-biznesa, страница пока 404, пишется в #504/#505).

## Как устроен раздел сейчас
- /uslugi/ — ресурс 18, template 13: `<h1>Услуги</h1>` + `[[$np_services]]` (4 карточки: логотипы, сайты, упаковка, реклама; «Упаковка» ведёт на /koordinatyi#request, ресурс 21 не опубликован) + `[[$np_support]]` (блок «После запуска»: /podderzhka/prodvizhenie, /podderzhka/podderzhka, /podderzhka/soczseti; контейнер podderzhka/ — ресурс 8, не опубликован).
- То есть «категория» на сайте = блок на странице /uslugi/; отдельных страниц категорий нет.

«Автоматизация бизнеса» — запрос про 1С/CRM/учёт (интеграторы), не про ИИ и не про студию. «Интеграция ИИ» — слабый спрос, в хвостах шум («ии интеграция фото»). В подборе «внедрение ии» много чужого: суды, госуправление, образование, курсы.

## Варианты названия
1. **ИИ для бизнеса** (рекомендация) — 578 точных, понятно без пояснений, вмещает любые будущие ИИ-услуги.
2. Автоматизация с ИИ — 155 («автоматизация бизнеса с помощью ии»).
3. Автоматизация — 472, но приводит людей, ищущих 1С/CRM.
4. Интеграция ИИ — 23 (92 с «в бизнес»).

## Адрес
Блок на /uslugi/ с якорем `#ii-dlya-biznesa` (для варианта 1). Отдельную страницу категории (`/uslugi/ii-dlya-biznesa`) — когда наберётся 2–3 услуги.
