# Призывы (CTA) в статьях блога (#538, 22.10, вариант 3 Лены)

Два спокойных блока на статью блога (parent 2, template 8), не больше двух:
1. **Середина** — свой блок под тему статьи: заголовок, 1–2 строки, кнопка (`<details>`) раскрывает форму в статье (имя, контакт, пара слов о задаче). Стоит перед 3-м H2 (TV `npCtaPlace` меняет номер).
2. **Конец** — после текста/даты, перед «Ещё интересное»: блок по услуге, на которую статья ссылается (первая ссылка `/uslugi/<alias>` из известных), с той же формой и ссылкой на услугу.

## Как устроено
- Template 8: после `[[*content]]` — `[[!npArticleCta? &pos=`mid`]]`, после автора — `[[!npArticleCta? &pos=`end`]]`; article.css?v=7, article.js?v=6.
- Сниппет `npArticleCta` (id 98): только parent 2; включён для id ≥ 104 (новые статьи сами), TV `npCtaMode` (24): off — выключить, on — включить в старой статье. Тексты середины — TV `npCtaTitle`/`npCtaText`/`npCtaButton` (25–27), пусто → текст `mid` по услуге. Тексты конца и `mid` по умолчанию — чанк `np_cta_services` (108, JSON: aliases адрес услуги → ключ; 103, 19, 20, 22, default).
- Средний блок сниппет выводит в конце текста в обёртке `div.np-cta-slot` + `i.np-cta-slot-end`; плагин `npArticleCtaPlace` (id 20, OnWebPagePrerender, priority -200) переносит его перед N-м H2 внутри `.article-content`. Меньше двух H2 — средний блок не показывается. HTML-комментарии как метки нельзя: MinifyX их вырезает.
- Форма: AjaxForm+FormIt, чанк `np_cta_form` (106), письмо `np_cta_email` (107: как project-form__email + строка «Форма: призыв в статье блога (середина/конец статьи)» + ссылка на страницу). Получатели и тема — как у «Обсудить проект» (request_form, /koordinatyi#request): `redegun@gmail.com,[[++e-mail]]`, «Непросто. Сообщение из формы обратной связи». Honeypot `email:blank`, hooks spam,email.
- Ответ формы показывает article.js в своём блоке (`af_complete`); custom.js AjaxForm пишет в `.form__results`, которых в статье нет.
- CSS/JS дописаны в конец article.css/article.js (блок `task 538`). Кнопка «+/−» как в «Содержании», hover только для мыши, автофокус поля только на десктопе.
