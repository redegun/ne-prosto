## Интерактивная экскурсия

Опубликована в кейсе в #tour, между разделами 02 и 03. Отдельный URL: https://ne-prosto.ru/images/portfolio/stankin/tour-20261008/. Оригинальная геометрия всех восьми вагонов; оформление получено из https://disk.yandex.ru/d/bdfd9VL_DXS0ZQ. Список переключает модели, внутренний режим даёт движение по проходу, экскурсия — пять точек.

Старт — крупный внешний вид вагона 1 с платформы. По краям есть кнопки перехода к соседним вагонам; «Весь поезд» отдельно включает общий вид и вторым нажатием возвращает к выбранному вагону. Нажатие на геометрию, номер или выбор в списке открывает соответствующий подробный интерьер. Режим «Снаружи» после салона возвращает крупно тот же вагон, также есть кнопка «Ближе». Модели 2.52–2.93 МБ, Draco, базовые атласы 4096px. Для надписей загружаются только видимые HD-фрагменты исходных 24–25 тыс. px: 6 слотов на десктопе / 4 на мобильной ширине; комплект 196 МБ не скачивается целиком. Материалы и свет настроены отдельно: тёмный графитовый пол, светящиеся оригинальные потолочные лампы, тёмно-синие сиденья, металл, прозрачное стекло, умеренная экспозиция и контактное затенение. По просьбе Антона снаружи сделана тёмная условная станция с колоннами, перроном и редкими локальными лампами. Конкретная реальная станция не воспроизводится. До клика в кейсе iframe/GLB не загружаются. Наружные развёртки предоставлены 15.10.2026: https://disk.yandex.ru/d/T2sgQL_nKO3pYA, восемь JPG 24000². Совмещены с внутренними по исходным UV (граница y=0.425), без повторного экспорта GLB. Общий вид использует отдельные облегчённые overview/car-N.glb (10.73 МБ суммарно, около 453 тыс. треугольников, совмещённые атласы 1536²). Подробные салоны загружаются только при входе; обзор и подробная модель освобождают ресурсы друг друга. При близком внешнем осмотре HD-текстуры подключаются только к текущему вагону (6/4 слота); смена вагона освобождает HD и восстанавливает исходные shader hooks. Порядок освобождения важен, иначе остаются ссылки на уничтоженные текстуры. Прежние наружные атласы 4096×1741 и HD-фрагменты сохранены в детальном режиме. При близком осмотре показывается потолок станции, пока камера находится внутри зала. В общем виде крыша открывается. Внешняя станция — архитектурный разрез с перроном, колоннами, рельсами, балками и светильниками; без сплошной крыши, заслоняющей состав. Экспозиция снаружи .78, environment .32, направленный свет .85/.25. Внутри сохраняется contrast1. Drag/pinch не должны открывать вагон; для клавиатуры и мобильных доступны номера 1–8. Стартовая камера автоматически вписывает видимый корпус выбранного вагона, без учёта уже скрытых платформой колёс. Полный состав вызывается отдельно; resize пересчитывает дистанцию до ручного перемещения. W/S и ↑/↓ приближают/отдаляют, A/D и ←/→ перемещают вдоль поезда вместе с центром вращения. Перед жестом центр уточняется центральным лучом по геометрии/плоскости поезда без скачка взгляда; колесо приближает к курсору, чувствительность вращения .55. Клавиатура работает при фокусе внутри viewer, после загрузки фокус на модели. Область нажатия по каждому вагону не менее 44 px по высоте. Дальность тумана и clipping адаптируются к дистанции камеры, чтобы портретный общий вид сохранял цвет.
