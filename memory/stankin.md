# Кейс СТАНКИН

Кейс https://ne-prosto.ru/portfolio/poezd-stankin — MODX resource 100, parent 23, template 15, menuindex 47. Живой сайт: Timeweb, FTP ne-prosto/public_html. Доступы берутся только серверно из clients/antonvetrov/ACCESS.md. Источники: content/stankin-20261002/.

Антон подтвердил: студия создала концепцию, дизайн и полную 3D-модель поезда; на модели подгоняли графику для плёнки и делали визуализации заказчику. Роли команды записаны в кейсе. Фото ГЦК требуют ссылку на фотобанк и имя Георгия Василькова; рендеры подписаны как рабочий этап. Не выдавать примеры и цифры из исходной концепции за реализованные факты.

В кейсе 14 фотографий результата, 5 рабочих рендеров и 4 видео (ГЦК, СТАНКИН, НТВ, 360). Для запуска экскурсии один рабочий рендер дополнительно используется как постер.

## Интерактивная экскурсия

Опубликована в кейсе в #tour, между разделами 02 и 03. Отдельный URL: https://ne-prosto.ru/images/portfolio/stankin/tour-20261008/. Оригинальная геометрия всех восьми вагонов; оформление получено из https://disk.yandex.ru/d/bdfd9VL_DXS0ZQ. Список переключает модели, внутренний режим даёт движение по проходу, экскурсия — пять точек.

Старт — вагон 1, также есть кнопка «Ближе». Модели 2.52–2.93 МБ, Draco, базовые атласы 4096px. Для надписей загружаются только видимые HD-фрагменты исходных 24–25 тыс. px: 6 слотов на десктопе / 4 на мобильной ширине; комплект 196 МБ не скачивается целиком. Материалы и свет настроены отдельно: нейтральный пол, тёмно-синие сиденья, металл, прозрачное стекло, умеренная экспозиция и контактное затенение. Условный зал за окнами нужен для глубины, не представляет реальную станцию. До клика в кейсе iframe/GLB не загружаются. Наружные развёртки ещё не предоставлены, поэтому внешний режим скрыт; оставшаяся задача — https://github.com/redegun/ne-prosto/issues/2.
